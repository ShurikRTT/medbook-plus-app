# Medbook+ — запрос для разбора дневниковой записи

Скопируйте текст ниже в любую ИИ-модель. После строки `ИСХОДНАЯ ЗАПИСЬ` вставьте свою запись. Ответ модели должен состоять только из JSON.

```text
Ты структурируешь одну дневниковую запись для Medbook+. Это не медицинская консультация и не диагностика: не добавляй сведения, которых нет в исходной записи.

Верни только один JSON-объект без Markdown, без пояснений до или после JSON.

Правила:
1. journalDate — дата записи в YYYY-MM-DD. Если дата не указана или неоднозначна, верни пустую строку и добавь предупреждение в notices.
2. sourceText — исходный текст без исправлений.
3. Разделяй отдельные эпизоды боли. Время — HH:MM или null. Указывай место боли только если оно есть в тексте; иначе пустая строка.
4. Шкала level: none=0, discomfort=1–2, mild=3–4, moderate=5–6, pronounced=7–8, severe=9–10. Если интенсивность приблизительная, classificationPrecision="approximate". reportedIntensity сохраняет исходную формулировку (например, "6–7").
5. Симптомы — короткие отдельные строки, без повторов.
6. Препарат связывай с болью через painIndex (нумерация с 0), если в тексте ясно, что он дан для конкретного эпизода боли. Если он относится к явно названному симптому, contextKind="symptom" и contextSymptom. В остальных случаях contextKind="general". Не придумывай дозу, эффект или время.
7. effectAfterMinutes — только целое число минут или null. measuredAt и takenAt — HH:MM или null.
8. Измерения: вес, рост, давление, температура, сатурация и другие явно записанные величины. Для давления записывай значение целиком, например "110/70", единицу "мм рт. ст.".
9. notices содержит только реальные неоднозначности и пропуски, требующие проверки.

Строгая структура ответа:
{
  "journalDate": "",
  "sourceText": "",
  "painObservations": [
    {
      "observedAt": null,
      "level": "none|discomfort|mild|moderate|pronounced|severe",
      "reportedIntensity": null,
      "classificationPrecision": "exact|approximate",
      "location": ""
    }
  ],
  "symptoms": [],
  "medications": [
    {
      "name": "",
      "dose": "",
      "takenAt": null,
      "effectAfterMinutes": null,
      "effect": "",
      "contextKind": "general|pain|symptom",
      "painIndex": null,
      "contextSymptom": ""
    }
  ],
  "measurements": [
    { "name": "", "value": "", "unit": "", "measuredAt": null }
  ],
  "notices": []
}

ИСХОДНАЯ ЗАПИСЬ:
<вставьте здесь текст записи>
```

## Как использовать ответ

Это проверяемый обменный формат. Перед переносом в Medbook+ проверьте даты, время, связь препарата с эпизодом боли и все измерения. Прямой импорт такого JSON в приложение пока не реализован: поля нужно перенести в форму «Подсказать из текста» / редактор записи.
