# Medbook+ — запрос для разбора анализов

Используйте шаблон для PDF, фотографии бланка или скопированной таблицы. После строки `ИСТОЧНИК` прикрепите PDF/изображение или вставьте текст. Ответ модели должен состоять только из JSON.

```text
Ты переносишь лабораторные результаты в Medbook+. Это извлечение данных, не медицинская интерпретация. Не добавляй и не исправляй медицинские сведения от себя.

Верни только один JSON-объект без Markdown и пояснений.

Правила извлечения:
1. Переноси только результаты текущего исследования. Никогда не переноси столбцы «предыдущий результат», «предыдущие значения» и прошлые даты как новые результаты.
2. Разделяй бланк на логические groups: например «Общий анализ крови», «Биохимический анализ крови», «Общий анализ мочи», «ПЦР и серология».
3. Для каждой группы укажи текущую дату YYYY-MM-DD, laboratory, общий method и все строки. Если даты/раздела нет, оставь пустую строку и объясни это в notices.
4. Сохраняй название показателя, результат, единицы и референсы максимально близко к бланку. comparator допускает только null, <, >, <=, >=.
5. Звёздочка отклонения не входит в valueText. isAbnormal=true, если бланк явно отметил отклонение; иначе false или null, если неизвестно.
6. Если в ячейке результата написано «см. комм.», «см. комментарий» или аналогично, найди комментарий именно этой строки. Если там есть фактическое значение, перенеси его в valueText и unit; исходную ссылку и комментарий положи в sourceText. Если фактического значения нет, оставь valueText="см. комм." и добавь notices.
7. Метод, относящийся только к одной строке, записывай в row.method. Ничего не придумывай.
8. category: laboratory для анализов, vision для зрения, other для прочих исследований.

Строгая структура ответа:
{
  "batches": [
    {
      "date": "YYYY-MM-DD",
      "category": "laboratory|vision|other",
      "group": "",
      "laboratory": "",
      "method": "",
      "rows": [
        {
          "name": "",
          "component": "",
          "comparator": null,
          "valueText": "",
          "unit": "",
          "referenceText": "",
          "method": "",
          "sourceText": "",
          "isAbnormal": null
        }
      ]
    }
  ],
  "notices": []
}

ИСТОЧНИК:
<прикрепите PDF/изображение или вставьте текст бланка>
```

## Резервный формат для текущей ручной вставки в Medbook+

Если нужен именно текст, который можно вставить в поле «Результаты», после проверки JSON попросите ИИ выдать отдельный блок для **одного** раздела в TSV:

```text
Показатель\tЗначение\tЕдиница\tРеференс
Гемоглобин\t129\tг/л\t115–148
СОЭ\t< 5\tмм/ч\t2–15
```

Текущая ручная форма понимает эти четыре колонки. Она пока не использует колонки «дата», «раздел», «лаборатория» и «метод» из TSV — это известное ограничение. Поэтому полный JSON выше сохраняет все сведения и подходит для будущего прямого импорта.
